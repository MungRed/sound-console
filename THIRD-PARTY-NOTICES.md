## Windows APIs

Sound Console uses Windows APIs (WASAPI, DWM, User32) exposed by the operating
system. No Windows SDK binaries are redistributed.

Segoe UI, Segoe UI Symbol, Cascadia Mono/Consolas). No font files are bundled.
